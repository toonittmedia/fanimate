**Fanimate 0.3.1** is a polish release: safer deleting, no editing while the animation plays, Draw tools that are always there, and a better way to parent bones. It is still an alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.3.0 offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file. The file format is unchanged (still version 6).

## Before you update

- **Delete no longer deletes layers.** Delete (and Backspace) now remove what you are working on: the picked keyframes in the timeline, chosen points, picked shapes, or the selected bone. With only a layer selected, nothing is deleted and the status bar says so. **Ctrl+Delete deletes the selected layers** (the Layer menu, the Layers panel and right-click menus do the same).
- **Nothing can be edited while the animation plays.** Press Space to pause first. The editing panels grey out, the canvas tools stand still, and edit commands and shortcuts say "Pause playback to edit." This stops keyframes being sprayed along the timeline by a click at a moving playhead.

## New in this release

### Drawing

- **The Draw and Fill tools always show**, as in Moho, whatever is selected. Draw with a bone layer, a group or nothing selected and Fanimate makes a new vector layer for it (inside the group or rig, if one is selected).
- **The Style panel's shape list no longer has a scroll area of its own.** The whole panel scrolls, so small screens have one place to scroll, not a list inside a list.

### Bones

- **Reparent Bone** is a new tool in the Bone group, and it works as it does in Moho: drag from a bone onto the bone that should be its parent, or drag to empty space to leave it with no parent. The new parent is named beside the pointer, with an arrow from the bone to it. The bone stays where it is, and its keys keep the same pose.
- **Arrows show the parenting.** With Reparent Bone, every bone gets an arrow to its parent (a dashed arrow when it starts away from its parent's tip, a small arrowhead on the parent when they join end to end); with Select Bone, the picked bone's. The tree in the Bones panel has the same arrows on its connector lines.
- **The Bones panel is a tab beside Layers** in the Animate and Rig workspaces, where it has more room (Window > Reset Layout or Window > Workspace brings the new arrangement to an existing layout). It is a tree with open and close arrows, guide lines, a bone icon and shaded rows. Drag a row onto its new parent (the middle of a row makes a child, the edge makes a sibling), or below the list for a root bone. Right-click a bone for *Select Parent*, *Parent To*, *Make Root Bone*, *Rename* and *Delete Bone*. In a wide panel the bone's settings sit beside the list so it does not jump when you pick a bone; the Parent menu lists the tree and greys out choices that would make a loop.
- Reparenting used to be able to put a bone before its parent, which broke the rig silently. The skeleton now always keeps parents ahead of their children.

### Interface

- The status bar no longer shows its message twice when you hover it (the same for the FFmpeg path in Export).
- Frame numbers in the Properties panel (the rest-pose note, a sound's start and length, the frame range and its time) now use the monospaced font like every other frame number.
