**Fanimate 0.3.2** adds eight templates: four basic ones and four full football-parody scenes with spoken dialogue and lip sync. It is still an alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.3.1 offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file. The file format is unchanged (still version 6).

## New in this release

### Templates

Open them from the Home tab (*See all templates*) or File > Open Sample. Each opens as a new, unsaved file.

- **Bouncing ball:** four bounces, each lower than the last, with squash and stretch and a shadow, keyed on the ball's position and scale.
- **Character rig:** a cartoon character on six bones that breathes, blinks and nods, with a switch layer of mouth shapes ready for Lip Sync.
- **Talking head:** one character saying a line, lip synced.
- **Mouth styles:** five faces, five mouth styles and one voice, so the styles can be compared and the one you want copied out.
- **Four football-parody scenes** (15 to 22 seconds each): *Dressing room*, *Press conference* (with camera flashes), *Penalty shootout* and *Studio pundits*. Each has a drawn set, two cartoon characters on bone rigs, dialogue, and mouth shapes keyed to the words frame by frame. Every character is made up.
- **Five mouth styles in SVG** (Classic, Flat, Ink, Line and Cute), nine shapes each, named A to H and X so Lip Sync finds them. The scenes use a photo-real frontal mouth set instead, with Smile and Surprised as extra shapes to key by hand.
- The dialogue is spoken by the computer's own voices (Microsoft David and Zira), so it sounds synthetic. Replace a sound and run Lip Sync to redo the mouths.

### For contributors

- The artwork and speech are generated by scripts (`scripts/template-art/`, `scripts/template-speech/`); `crates/fanimate-editor/assets/templates/README.md` says how. `fanimate-cli sample <template-name> out.fnm` writes any template to a file.
- Fanimate is about 3.5 MB larger because the templates are built in.
