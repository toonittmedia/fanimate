**Fanimate 0.5.1** lets you run plugins from inside the app, turn the canvas, and keep a smaller game file, and it tightens the new 0.5.0 features: keyboard shortcuts, right-click menus, manual chapters and a lot of hostile-input testing. It is still a closed alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.5.0 offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file.

The project file format is unchanged (still version 7): projects from 0.5.0 open as they were.

## What this release is not

Phase 2 is **not finished**. Still to come: raster layers and the brush engine, the node graph, symbols and the Library, running plugins' own panels and commands, and the AI models beyond the three classical helpers. This release lists only what is built.

## New in this release

### Plugins from inside Fanimate

- **Window > Plugins** lists the plugins in your plugins folder (Open Plugins Folder takes you there). Choose one and Fanimate asks first, in words, what it wants to do to the project: read it, change it. **Run** runs it once, **Always allow and run** remembers that exact plugin version and permission list (a new version, or a plugin that asks for more, asks again).
- A plugin is a program, and **Fanimate limits what it does to your project, not to your computer**. The prompt says so: run only plugins you trust.
- **Everything a plugin does is one undo step**, however many calls it made, and **Window > Plugins > Stop Plugin** ends it. A plugin that runs from the app cannot save the project: use File > Save when it has finished.
- Make one with `fanimate-cli plugin new`; see [Plugins](https://github.com/toonittmedia/fanimate/blob/main/docs/plugins.md).

### Rotate Canvas

- **View > Rotate Canvas**, or **Ctrl+Alt+Left** and **Ctrl+Alt+Right**, turns the view 15 degrees; **Shift + middle-drag** turns it freely. **Ctrl+Shift+0**, or a click on the angle in the status bar, turns it upright.
- Only how you look at the animation turns. The artwork and what is saved are not changed, and drawing, selecting and the transform handles work as usual. The grid turns with the view. While it is turned the rulers are off (the angle shows in their corner) and guides are shown but cannot be moved.

### Smaller game files, and what a file would cost

- `fanimate-cli export scene.fnm -o scene.fnmr --tolerance 2` leaves out keys the game would not miss (the tolerance is how far, in document units, any point may be drawn from the exact frame). A straight move is two keys; a rig that swings its limbs through big angles keeps most of its keys, because a turn is not linear. The file is an ordinary version 1 file, so every runtime reads it.
- `--estimate` on a Lottie or runtime export says how big the file would be and how many keys it has, and writes nothing.

### Shortcuts and menus for the 0.5.0 helpers

- Clean Up Lines **Ctrl+Alt+L**, Suggest Inbetween **Ctrl+Alt+I**, Auto-Rig Character **Ctrl+Alt+R** and Offset Path **Ctrl+Alt+O**, in both keyboard sets. **Assist** is now in the right-click menu of layers, on the canvas and in the Layers panel, as well as in the Edit menu.
- A new manual chapter ([helpers that need no AI](https://github.com/toonittmedia/fanimate/blob/main/docs/manual/README.md#6b-helpers-that-need-no-ai), poses, canvas rotation, plugins) and the new export routes in the Exporting chapter.

### Harder to break

- The scripting call table is fuzzed: every call is made with its own parameters mangled in the ways a script or plugin could (wrong types, huge, negative and non-finite numbers, deep nesting, missing and extra keys), a call that fails must change nothing, and a client without the edit permission must change nothing through any call. Every exporter (animated SVG, runtime file, Lottie, OpenTimelineIO, one frame as SVG) is tried on projects with zero, negative and non-numeric frame rates and sizes, backwards and enormous ranges, and shapes with damaged points: each makes a clean file or says why not. No panics were found, and these tests now keep it that way.

### For people who test Fanimate

- `FANIMATE_DATA_DIR` makes a copy of Fanimate keep its settings, crash reports, recovery files, pose library and plugin permissions in another folder, so a test copy never touches the real ones.

## Known limits

- Rotating the canvas does not yet keep the angle in the project, and guides cannot be dragged from a turned ruler.
- A plugin run from the app has no panels or menu items of its own yet.
- The Offset distance and the Clean Up tolerance are settings of the editor, not saved in the project.
