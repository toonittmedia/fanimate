**Fanimate 0.5.0** adds an in-app Assistant, plugins, three drawing and rigging helpers that need no AI, new ways to get animations out (animated SVG, a game runtime format, a timeline for editing programs), a personal pose library and Offset Path. It is still a closed alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.4.x offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file.

The project file format is unchanged (still version 7): projects from 0.4.x open as they were. Projects saved by 0.5.0 open in 0.4.1 unless they hold layers marked as made by a tool (the Assistant or the helpers below), which 0.4.1 reads too.

## What this release is not

Phase 2 is **not finished**. Still to come: raster layers and the brush engine, the node graph, symbols and the Library, canvas rotation, running plugins from inside the app, and the AI models that go beyond the three classical helpers below. This release lists only what is built.

## New in this release

### The Assistant

- **Ctrl+K** (or **Ask** in the title bar) opens a chat column. Ask for an animation or an edit in words; the Assistant works through the same calls scripts use, so every change is one undo step and every layer it makes is labelled as made by the Assistant.
- It runs only when you allow it: choose a provider (Anthropic or an OpenAI-style service, including one on your own computer), paste your key (kept in its own file, never in a project or a log), and allow sending to that address. **Turn off all AI features** and the *Work offline* setting switch it off completely. On a small window the Assistant takes the place of the right-hand column while it is open.
- **Let other programs control Fanimate** lets an agent such as Claude Code or Codex work on the open project through a local, password-protected connection. `fanimate-cli mcp` serves Fanimate to agents headless.
- Read [docs/assistant.md](https://github.com/toonittmedia/fanimate/blob/main/docs/assistant.md) for exactly what is sent.

### Plugins

- A plugin is a folder with a `plugin.json` and a program (Python, JavaScript, TypeScript or any program) that talks to Fanimate over the scripting API with **only the permissions it declares**. It runs as a separate process with a time limit, a call limit and a size limit, and a crash in a plugin never touches your project.
- `fanimate-cli plugin new`, `test`, `run`, `pack`, `install` and `list` make, try, share and install plugins. `.fnplugin` packages install without running anything and refuse unsafe paths. A Node client joins the Python one in `clients/`.
- **A plugin is not sandboxed from your computer**, only from your project: install plugins only from people you trust. See [docs/plugins.md](https://github.com/toonittmedia/fanimate/blob/main/docs/plugins.md). Running plugins from the app, with a permission prompt, is not built yet.

### Helpers that need no AI (Edit > Assist, and Properties > Outline)

- **Clean Up Lines** refits a rough, wobbly line with fewer, smoother curves that stay within a tolerance you set, keeping the corners you drew and a brush stroke's thick and thin.
- **Suggest Inbetween** adds a drawing between two frame-by-frame drawings, moving points along arcs so a swinging arm keeps its length. Undo it if you do not like it, and edit it like any drawing.
- **Auto-Rig Character** builds bones from layer names such as torso, head, upper arm, forearm, thigh and shin (with L, R, A, B, left or right), binds each layer, and puts them in a new bone layer, without moving the art. A character with no torso is refused, and a layer that names no body part stays where it is.
- Each one works offline, is one undo step, and marks the layer it changed or made so the file says what was assisted.

### Offset Path

- **Edit > Combine Shapes > Offset Path** (and the new **Outline** section of Properties, where you set the distance) adds an outline a set distance outside a shape, or inside when the distance is negative.

### Your own pose library

- Right-click an action in the Actions panel and choose **Save to My Poses**. The pose is then in **My poses** at the bottom of the panel for every project: click it to add it to the selected rig, which pairs bones by name and keeps each bone's turn from its own rest angle, so a wave made on one character works on another.

### Getting animations out

- **Animated SVG.** `fanimate-cli export scene.fnm -o scene.svg`, or File > Export for Web and Games. A file browsers play on their own, with no script and no player. Inkscape and Illustrator show only the first frame.
- **Runtime file (`.fnmr`).** The animation as baked slots with transform keys for games and web pages, with a small JavaScript player in `runtimes/web/` and the format written down in [docs/spec/runtime.md](https://github.com/toonittmedia/fanimate/blob/main/docs/spec/runtime.md). A rigged character plays exactly as it looks in Fanimate, but a game cannot repose it: bones and meshes are not in version 1.
- **Timeline for editing programs (OpenTimelineIO).** `-o scene.otio`, with `--video movie.mp4` to name your rendered movie. It carries timing and sounds (each sound placed, trimmed and written beside the file), not drawings. It follows the OpenTimelineIO schema but has not been opened in the reference library yet.
- As before, each export lists what it could not carry (pictures, masks, width profiles and so on) rather than leaving it out silently.

### Smaller changes

- The Assistant column and the right-hand column no longer squeeze the canvas on a 1366-pixel window.

## Known limits

- The new menu items, the Assistant and My poses have been used and looked at in a real window, but not by a person other than the developer.
- The Offset distance and the Clean Up tolerance are settings of the editor, not saved in the project.
- The runtime format is version 1 and may change before 1.0.
