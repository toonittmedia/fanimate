**Fanimate 0.2.3** is a second usability pass. It fixes what was broken (links that did not open, hidden grid, the Line Width and Draw Shape tools, guides coming from the wrong side), tidies the dialogs, and adds what you asked for: a camera, colour animation, Moho-style keying, per-property keys on the timeline, shape selection from a list, audio import in more formats, and progress for updates and renders. It is still an alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.2.2 offers this update itself, and now shows its progress in the status bar while it downloads. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file.

## Before you update

- **The file format is now version 5.** Files from every earlier version open as before. A project saved by 0.2.3 cannot be opened by 0.2.2 or earlier, so keep a copy if you need to go back.
- **Keying works like Moho now.** On the first frame, editing a layer, a shape's points or a colour changes it for the whole animation. On any later frame, the edit sets a key (and a key on the first frame is added so it does not jump). Before, only already-animated values were keyed.
- **Ctrl+R is Render Preview Frame** and **Import moved to Ctrl+I** in the default keymap.
- **The High Contrast theme is gone.** A setting that names it falls back to Studio Grey.

## New in this release

### Camera

The project has one **camera**, like Moho's: not a layer. It is the first row of the timeline. Open it (double-click, or the arrow) to key **Position, Zoom and Roll** each on its own; the Properties panel shows the same fields with key buttons when no layer is selected. Renders and exports see the canvas through the camera. **View > Look Through Camera** shows it on the canvas, and the camera's frame is drawn when it is not looking at everything. Reset Camera puts it back.

### Colour animation

Fill and stroke colours can be keyed. Change a colour on a later frame and it is keyed; the shape's right-click menu has Key Fill Colour Here and Key Stroke Colour Here. The Style panel and the selection bar show the colour at the current frame.

### Timeline

- **Open a layer** (double-click, or the arrow) to see its properties as rows: Opacity, Position, Rotation, Scale, each bone, a switch layer's choice. Every row has its own keys: click to move the playhead, drag to retime, right-click to add, delete or change interpolation.
- **Key buttons in Properties** next to every animatable value.
- **Interpolation colours.** Smooth keys stay amber, linear keys are blue and step keys are red. A dropdown beside the key buttons chooses the interpolation that new keys take.
- **The playhead can go past the end**, so you can add a key there. Playback still loops the playing range. Scrubbing near either edge scrolls the timeline.

### Drawing tools

- **Line Width** now hovers the nearest point on any stroke and drags up or down to change its width, with the width shown beside the pointer. Selected points change together.
- **Draw Shape** sketches freehand: drag an outline, release, and it is smoothed and closed into a filled shape.
- **Shapes list.** The Style panel lists the layer's shapes: click, Ctrl-click and Shift-click to select, double-click or F2 to rename, an eye to hide one, and a right-click menu.
- **Lock a layer** (padlock in the Layers panel, Ctrl+L). Locked layers still draw and play, but cannot be selected or edited.
- **Align** (left, centre, right, top, middle, bottom, to the canvas or the selection), and a floating toolbar you can drag by its grip.
- **Change layer type**: right-click a group, bone or switch layer and choose Change to. Fanimate asks first only when something would be lost, and says exactly what.

### Rulers, grid and snapping

- Guides come out of the correct ruler (the top one makes horizontal guides, the left one vertical) and show while you drag them in. They are saved in the project, can be dragged afterwards, and dropped back on a ruler to delete.
- The grid and guides are drawn over the artwork's picture, so they are visible. Vertical ruler numbers are turned to read upward.
- **Snap to shapes**: other shapes' points, edges and centres. Snapping works on both axes at once.

### Dialogs

- **Preferences** has a category list on the left (General, Interface, Canvas, Video).
- **Export** is laid out in groups: format, size, frames (with **Entire animation** beside the range), then folder and name, with an Overwrite checkbox. A file that exists is no longer replaced silently.
- **Places you used** (folders for Export and Save As) are remembered and offered in a dropdown. **Save As Folder** is in the File menu.
- Preferences, Export, Keyboard Shortcuts, About and Update are **modal**: the rest of the app waits, like a system alert. The Keyboard Shortcuts window no longer jumps.
- **Render Preview Frame** (Ctrl+R) renders the current frame with the same renderer as export and shows it, with Save as PNG and Copy.
- **What's New** (Help menu) shows these notes inside Fanimate, and opens once after an update.
- **Links open the browser** (Help menu, About, Update).

### Layout and Home

- The **canvas is no longer a tab**: it always fills the middle. Panels sit around it, and **History** is hidden until you open it from Window, when it joins the Layers panel.
- The **tools panel** shrinks to three tools per row without wasted space.
- Home cards no longer overflow, and **Recent** and **Templates show previews**. Previews are made in the background and kept in Fanimate's data folder.

### Media

- **Import MP3, OGG, FLAC, AAC and M4A** as audio layers (converted to WAV inside the project, so scrubbing stays fast). Drag a file onto the window to import it. Damaged files give a message, never a crash.

### Updates and progress

- Updating no longer freezes the window: the status bar shows a progress bar and the percentage.
- On Windows, **render progress also shows on the taskbar button**.

## Not there yet

- **Stroke Exposure**, separate radii for each corner and a keyed pivot are not built (they need more format fields).
- **Offset Path**, and snapping for Freehand, Eraser and the selection handles, are not built.
- **Dragging the camera on the canvas** is not built: use the Properties panel or the timeline.
- **Previews for recent projects** are made by Fanimate and kept in its data folder, not stored inside the project file.
- "Your files" on the Home tab and templates beyond the three samples are not built.
- **Video import** is only a design note: [`docs/roadmap/video-import.md`](https://github.com/toonittmedia/fanimate/blob/main/docs/roadmap/video-import.md).
- MP3, OGG, FLAC and AAC import is tested with generated WAV files and damaged input, not yet with real files of each format.
- On macOS, opening a file from Finder into an already running Fanimate has not been tested, and the update install still runs on the main thread there.

## Behind the scenes

- File format version 5: `camera` and `guides` in `document.json`, layer `locked`, shape `visible`, `fill_keys` and `stroke_keys`. The specification is in [`docs/spec/fnm.md`](https://github.com/toonittmedia/fanimate/blob/main/docs/spec/fnm.md); the validator checks every new field and the round-trip and damaged-projects tests cover them.
- Audio decoding uses [symphonia](https://github.com/pdeljanov/Symphonia) (MPL-2.0, a file-level licence that fits the project's dependency rules; it is listed in `docs/legal/licences.md`).
