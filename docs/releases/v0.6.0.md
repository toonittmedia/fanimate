**Fanimate 0.6.0** fixes keys appearing by themselves while you scrub, makes switch layers much easier to work with (you see the layer you select, there is a dropdown to change the active one, and the active one is marked green), makes the lock buttons say what they did, and lets you share brush styles as files. It is still a closed alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.5.1 offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file.

The project file format is still version 7: projects from 0.5.1 open as they were.

## What this release is not

Phase 2 is **not finished**. Still to come: brush tip images, textures and the other brush dynamics, colour marks, the node graph, symbols and the Library, running plugins' own panels, and the AI models beyond the three classical helpers. This release lists only what is built.

## Fixed

- **Keys no longer spray while you scrub.** After you keyed a value (opacity, a controller, a text weight, a sound's volume) and then moved the playhead between keys, Fanimate wrote a new key on every frame you passed over. The sliders in the Properties panel re-rounded the value they were showing on every frame and counted that as an edit. They now change a value only when you do. The stray keys also showed up in the graph view, which draws the same keys.
- **Selecting a layer inside a switch shows that layer.** The canvas used to show only the switch's active layer, so a selected layer that was not active seemed to vanish. Now the layer you select is the one you see. Select the switch itself, or anything outside it, and the switch shows its active layer again. This is only how the canvas looks: renders and exports always show what the switch's keys say.
- **The padlock on a layer row now works.** It disappeared as the pointer reached it, so the click landed on the row instead. It now stays put while the pointer is anywhere over the row.
- **Delete removes a text animator.** With an animator picked (its row in the Text panel or its stick on the timeline), the Delete key now deletes it, as one undo step. Delete still takes chosen keys, points, shapes or a bone first when there are any, and never deletes a layer (that is Ctrl+Delete). Before, it only said "Nothing to delete here".
- **The lock buttons say what they did.** Locking or unlocking now shows a message in the status bar, and the padlock in the floating toolbar over the canvas shows a closed padlock when the chosen layers are locked and an open one when they are not.

## New

- **Shift locks a drag to a straight line.** Hold Shift while you drag a layer with the Transform tool, or points with Select Points, Transform Points or Add Point, and the movement stays on a horizontal or vertical line through where you started. The line is chosen once you have moved a few pixels (whichever way you have gone further) and kept while Shift is held; let go of Shift to move freely again.
- **A dropdown for switch layers.** Select a switch layer and the timeline's toolbar shows **Shows:** with the layer that is active on the current frame. Choose another to change it from the playhead on (it keys the switch, like the Show Layer menu, so a switch can still change over time).
- **The active layer of a switch has a green icon** in the Layers panel.
- **Style files.** In the Style panel, the "..." menu next to the style name has **Export style...** (a small `.fnstyle` file) and **Import style...** (adds it to your list and chooses it; a name you already have gets a number, so nothing is replaced). A style carries the raster brush's hardness, flow, pressure to flow and spacing.

## Also

- The README's build badge no longer says "failing" while releases succeed: it showed the manual test runs on the main branch and ignored the real releases, which build from tags. It now shows the latest release.

## Known limits

- Rotating the canvas does not yet keep the angle in the project, and guides cannot be dragged from a turned ruler.
- A plugin run from the app has no panels of its own yet.
- The Offset distance and the Clean Up tolerance are settings of the editor, not saved in the project.
