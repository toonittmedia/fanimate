**Fanimate 0.3.0** is a timeline and tools release. Frames now start at 1 with frame 0 as a rest pose, the timeline gets keyframe selection, copy and paste, scaling and loops, the Tools panel follows the kind of layer you are working on and gains camera tools, points have their own transform with a movable pivot, and the Style panel can save and manage styles. It is still an alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

## Before you update

- **The file format is now version 6.** Files from every earlier version open, and are converted as they load: every frame number goes up by one, so your animation plays exactly as before. A project saved by 0.3.0 cannot be opened by 0.2.3 or earlier, so keep a copy if you need to go back.
- **Frames start at 1.** A new project is frames 1 to 120. Frame 0 is the **rest pose**: a real frame you can stand on, for drawing and setting up. Edit on frame 0 and you change the thing itself; edit on any later frame and it is keyed, with a key placed on frame 0 holding what the value was. The command line takes the project's own frame numbers, so `--frame 1` is the first frame.
- **Ctrl+C and Ctrl+V follow where you last clicked.** On the canvas they copy points and paste shapes, in the timeline they copy and paste keyframes. **Layers use Ctrl+Shift+C, Ctrl+Shift+X and Ctrl+Shift+V** (Ctrl+D still duplicates). Pressing Ctrl+C on a selected layer no longer copies the layer.
- **Scale Points and Rotate Points are gone.** Select two or more points and use the Transform tool: it now scales and rotates the points about a pivot.
- **Freehand with Width is gone.** Freehand does both: turn **Pen pressure** on or off in the Style panel.
- **The Tools panel shows fewer groups.** Draw and Fill appear for vector layers and Bone for bone layers. With no layer selected, only Transform, Camera and Workspace show. A new blank project starts with a layer selected.

## New in this release

### Timeline

- **Select keyframes.** Click one, Shift-click to add, Ctrl-click to toggle, or drag a box over keys (from empty space in a row or below the rows). Selected keys have a ring; Esc clears, Ctrl+A selects all.
- **Move, copy, scale.** Drag a selected key to move them all; Alt-drag copies. With two or more keys selected, point just past either end and a small grip appears: drag it to stretch the keys in time (Alt stretches about the playhead). The new length shows beside the pointer in frames and seconds.
- **Copy and paste keyframes** with Ctrl+C and Ctrl+V. They keep their layer and channel and land with the earliest key on the playhead. Pasting into another tab puts them on the selected layer's matching channels.
- **Loop.** Right-click a key or channel and choose Loop: Repeat, or Repeat and offset (each cycle carries on from where the last one ended, so a walk keeps moving forward). A tinted bar with ghost keys runs from the last key to the end.
- **Layer order over time.** Reorder a layer on a later frame and the new order is keyed (stepped), so a hand can pass in front of the body at frame 40. An Order row appears for layers in groups.
- **Seconds and frames.** The ruler marks whole seconds, the transport shows the time (such as 1:17), and frame numbers use a monospaced font so the digits do not jump. The status bar shows both.
- **Names column.** Drag the line between the names and the frames to resize it (double-click resets); long names end with an ellipsis and show in full on hover.
- **Go to Rest Pose** (the button before First Frame, or the **1** key).
- **Hide layers with no keys** (Preferences > Interface). The Camera row appears only once it has keys.
- The interpolation drop-down highlights the whole row. The key menu's interpolation now applies to the selected keys wherever the playhead is.

### Tools

- **Camera tools** (Track, Zoom, Roll): drag on the canvas and the camera is keyed by the usual rule. The camera's frame is shown while one is active. Shift+T, Shift+Z and Shift+Y.
- **Transform points.** With two or more points selected, the Transform tool shows a frame with scale, rotate and a movable pivot. Edits follow the keying rule.
- **Set the pivot by clicking.** The target button on the floating toolbar and in Properties arms the pivot picker: the next click on the canvas places the pivot (snapping to the nine anchors; Shift for free). Esc cancels. The pivot and the rotate handle also snap to guides and other shapes.
- **Copy points, paste a shape.** Copy whole shapes, or just chosen points as an open path with the shape's style, and paste in place, into another layer or another tab.
- **Hide Edge** (Shift+H): click a segment of a shape to leave its stroke undrawn while its points and fill stay. Click it again, or Alt+click, to show it.
- **Freehand** is one tool with a **Pen pressure** checkbox (on by default; a mouse always draws at full width).

### Styles

Under **Brushes and new shapes** in the Style panel, one line chooses, saves and manages styles. A style holds line colour, width, fill, outline, smoothing, taper and pen pressure. The save button updates the chosen style when you have changed the look, and otherwise saves a new one; the menu has Save as new style, Update, Rename, Delete, Set as default and Reset to default. A built-in **Default** cannot be changed. Styles are kept by Fanimate and saved in the project, so another computer has them.

### Home

- **Your files:** add folders on the Home tab and the projects in them are listed with previews.
- **Templates:** Blank, Walk cycle rig (a twelve-bone stick figure with a walk), Lip sync (a face and nine mouth shapes set up for Lip Sync) and Frame by frame, besides the samples.
- **Previews are saved in the project file** (a small `thumbnail.png`), so Recent and Templates show them on any computer.

### Other

- **Paste from the Edit menu** reads the system clipboard like Ctrl+V does, and a copy made in one tab can be pasted in another from the menu too.
- A saved project that had a damaged coordinate (a point that is not a number) used to open but then fail to save. Such points now move to the origin on load, and the project saves.

## Not there yet

- A **keyed pivot** and **Offset Path** are not built.
- The **Eraser** does not snap (snapping it would erase away from the pointer).
- **Loop** applies to numeric channels (position, rotation, scale, opacity, bone angles, camera, layer order). Point keys, colour keys, stroke exposure keys and a switch layer's choice do not loop.
- The **camera tools, Hide Edge, Go to Rest Pose and the pivot picker have no keys in the Moho keymap**: Moho's own manual does not list keys for them, and Fanimate does not guess.
- Copying a frame-by-frame layer's summary key copies only the drawing.
- Scaling points about a pivot scales about the opposite side of their box, so the pivot matters for rotation only.
- **Video import** is only a design note: [`docs/roadmap/video-import.md`](https://github.com/toonittmedia/fanimate/blob/main/docs/roadmap/video-import.md).
- This release was checked by hand on **Windows** only. The macOS and Linux installers are built by the release workflow and have not been tried. Opening a file from Finder into an already running Fanimate on macOS has not been tested.
- No before and after performance numbers were taken for the new timeline and point-transform code; nothing was found slow, but the 60 fps budget has not been re-measured.

## Behind the scenes

- File format version 6: frames count from 1 (older files are converted on load), `loop_mode` on channels, `order` on layers, `hidden_edge_flags` on shapes, `styles` in `document.json`, and an optional `thumbnail.png`. The specification is in [`docs/spec/fnm.md`](https://github.com/toonittmedia/fanimate/blob/main/docs/spec/fnm.md); the validator checks every new field, and the migration, round-trip and damaged-projects tests cover them.
- JetBrains Mono (SIL Open Font License) is bundled for the monospaced numbers; its licence is in `brand/fonts/` and `docs/legal/licences.md`.
- The audio import tests now use real MP3, OGG, FLAC and AAC files (short generated tones).
