**Fanimate 0.4.1** lets text use the fonts installed on your computer, makes every kind of key easy to tell apart on the timeline, and adds OpenRaster import, a command that restyles all captions at once, expressions that bake to keys, and permissions for plugins and scripts. It is still a closed alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

Fanimate 0.4.0 offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info > Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file.

The project file format is unchanged (still version 7): projects from 0.4.0 open as they were, and projects saved by 0.4.1 open in 0.4.0.

## New in this release

### Fonts installed on your computer

- The **Font** menu in Properties now lists every font installed on the computer, under a search box, below the fonts Fanimate ships (Inter, JetBrains Mono and the Noto fonts for Arabic, Hebrew, Devanagari and Thai). The menu is wider, so long names fit.
- A text keeps the name of the font it was set in. Where the font has a separate bold file, text of weight 600 or more uses it.
- Exports, the render queue and the command line use the same installed fonts as the editor.
- If a project names a font the computer does not have, the text is set in Inter, Properties says so, and the name is kept: the project looks right again on a computer that has the font. The shipped fonts look the same on every computer, so use one of them (or **Convert Text to Shapes**) when a project must look identical everywhere.
- Scripts can list the fonts with the new `fonts` call.

### Keys you can tell apart

- Every kind of key has its own colour and picture on the timeline. Smooth stays amber and round, linear is a blue diamond, step is a red square. **Ease in, ease out and ease in and out are green circles** with their own curve drawn inside, and **overshoot, bounce, elastic and custom curves are purple circles**, each with its own picture. The colours are in all three themes.
- The interpolation menu beside the transport controls is wider, so "Ease in and out" no longer runs out of the box, and its marks are larger so the pictures can be read.

### Captions

- **Layer > Text > Restyle All Captions** makes every other caption in a set look like the selected one: font, size, colour, outline, alignment, animators and position, but not the words. Style one caption, run it once. One undo step.

### Pictures

- **OpenRaster (`.ora`) files import** from File > Import or by dropping them on the window. Krita, MyPaint and GIMP save this format. Layers come in as image layers with their groups, positions, opacity and visibility. A blend mode other than normal is shown as normal, and the status bar says how many layers that affected and how many could not be read.

### Scripting

- **Expressions that bake to keys.** `bake_expression` works a small expression out on every frame of a range and writes the answers as keys of one property: `value + 12 * sin(frame / 4)` is a wobble on top of what is keyed, and `100 - blink(frame, 7, 96, 4) * 100` makes a layer vanish for 4 frames at a random place in every 96. The random functions (`noise`, `random`, `blink`) give the same answer on every computer. The language has no loops, so it always finishes, and a frame with no answer (a division by zero, say) is reported by number and writes nothing. One undo step. See [Scripting Fanimate](https://github.com/toonittmedia/fanimate/blob/main/docs/scripting.md#expressions).
- **Permissions and plugin manifests.** A script host can give its client only `read`, `edit` or `save`: `fanimate-cli script --permissions read,edit`, or `--plugin plugin.json` to give a plugin what its manifest asks for. A call the client may not make is answered `permission_denied` and does nothing. `fanimate-cli plugin check plugin.json` reads a manifest and says what it asks for, or what is wrong with it. The Python client takes `permissions=` and `plugin=`. `api.methods` now lists the permission each method needs.
- New calls: `fonts`, `restyle_captions`, `import_ora` (the file as base64) and `bake_expression`.
