# Models Fanimate ships

Generated by `python scripts/models.py` from `models/registry.json`; do not edit by hand. `pnpm release` runs it with `--check`, which fails on a model that breaks the policy and on a stale record.

## The policy (decision D2-6)

**Permissive redistribution licences only; documented provenance; commissioned or donated data for any model Fanimate trains; no scraped art.** The lists below are `models/policy.json`, which the program (`fanimate-ml`) and this check both read.

- **Licences allowed** for weights: `MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Zlib`, `Unlicense`, `CC0-1.0`, `CC-BY-4.0`. An expression passes when one alternative of every `OR` is made only of these (`AND` needs all).
- **Needs a lawyer before any model under it is added:** a licence that limits how the weights may be used, that is, a name containing `NC`, `RAIL`, `Responsible`, `Research`, `Non-Commercial`, `NonCommercial`, `OpenRAIL`, `Llama`, `Gemma`. Responsible-AI, non-commercial, research-only and community licences with a use policy are all in this group. They are never allowed by default.
- **Provenance** is recorded for every model: what it was trained on, and how the data was gathered: `commissioned`, `donated`, `public-domain`, `permissive-open`. `unknown` is refused, and so is any model trained on art gathered from the web without its artists' consent.
- **A model Fanimate trains itself** uses commissioned or donated data with written consent, never scraped art and never the projects of Fanimate's users.
- **Packaging:** each model is a `.fnmodel` file, signed with the Ed25519 scheme that signs updates, with its SHA-256 and licence file inside; Fanimate verifies all of it when installing and again every time the model is loaded, and loads nothing while AI features are off. See `crates/fanimate-ml`.

## Models in this release

**None.** No model is bundled or offered for download in this release. The model manager, the signing and the checks are built and tested; a model is added to `models/registry.json` only after its weights licence, its training-data provenance and its quality on Fanimate's own test sets have been recorded and reviewed. The classical tools (line clean-up, inbetween assist and auto-rig) need no model.
